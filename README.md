# Atlas de la Tierra Media

Atlas interactivo y **no oficial** de las rutas de los personajes de _El Señor de los Anillos_:
mapa propio de la Tierra Media, línea temporal en paralelo y eventos, con los libros (Apéndice B)
como fuente canónica.

Proyecto fan sin ánimo de lucro. La cartografía es original (datos vectoriales propios); no
incluye mapas publicados, imágenes de las películas ni citas de los libros.

```bash
npm install
npm run dev        # http://localhost:5173
npm run check      # typecheck + formato + tests + validación de datos + build
```

Documentación del proyecto: [`CLAUDE.md`](CLAUDE.md) y [`docs/`](docs/).
